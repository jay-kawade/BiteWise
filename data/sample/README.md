# Sample / Demo Food Dataset

## What this is

`foods_sample.csv` is the food database used by this application in **DEMO_MODE**
(the default mode, requiring no external API keys). It is generated by
`generate_sample_foods.py`, which you can open to see exactly how every value
was produced.

- **105 food records** commonly eaten in Indian and general/continental diets
  (grains, legumes, dairy, meat/fish/eggs, vegetables, fruits, nuts, snacks,
  beverages, and composite/restaurant-style dishes).
- Every record has: name, category, serving size, calories, macronutrients
  (protein/carbs/fat), fiber, sugar, sodium, saturated fat, dietary type,
  most-common meal type, cuisine, allergens, and descriptive tags.
- Descriptive tags (`high_protein`, `high_fiber`, `high_sugar`,
  `high_sodium`, `high_saturated_fat`, `balanced`) are computed
  **deterministically** from simple per-100g thresholds defined in the
  generator script -- they are not derived from any external claim.

## Honesty about the source of these numbers

These are **approximate, commonly-known nutrition figures for everyday
foods** (the kind of numbers found on generic nutrition labels or general
nutrition references), compiled by the project developers as development/
demo data. They are:

- ✅ realistic enough to demonstrate every feature of the system end-to-end
- ❌ **not** sourced from one verified, citable nutrition database
- ❌ **not** suitable for clinical, medical, or research use
- ❌ **not** a substitute for laboratory-analyzed nutrition data

## How to replace this with a real, verified dataset

The rest of the codebase never reads this CSV directly -- it always goes
through `src/database/repositories.py`. To swap in a verified dataset:

1. Obtain a licensed/public dataset, for example:
   - **USDA FoodData Central** (public domain, U.S. Department of Agriculture)
     -- https://fdc.nal.usda.gov/ (free API key required for the live API)
   - **Indian Food Composition Tables (IFCT 2017)**, National Institute of
     Nutrition, ICMR -- widely cited for Indian foods
2. Map its fields onto the columns used in `foods_sample.csv`
   (see the column list below).
3. Save the mapped file to `data/raw/`, run your own preprocessing script
   (add one under `src/ml/preprocessing.py` or a new script), and write the
   cleaned output to `data/processed/foods.csv`.
4. Point `src/database/seed.py` at the new processed file (one constant at
   the top of that file).
5. Set the `source` column to the real dataset's name (e.g. `"usda_fdc"`)
   instead of `"demo_reference"` so the provenance stays traceable.

## Columns

| Column | Type | Meaning |
|---|---|---|
| name | text | Food/dish name |
| category | text | Broad food group (grain, legume, dairy, meat, fish, egg, vegetable, fruit, nuts, snack, beverage, composite, dessert, shellfish) |
| serving_size_g | number | Reference serving size in grams (or ml for beverages) |
| calories | number | kcal per serving |
| protein_g | number | Protein grams per serving |
| carbohydrates_g | number | Carbohydrate grams per serving |
| fat_g | number | Total fat grams per serving |
| fiber_g | number | Dietary fiber grams per serving |
| sugar_g | number | Sugar grams per serving |
| sodium_mg | number | Sodium milligrams per serving |
| saturated_fat_g | number | Saturated fat grams per serving |
| dietary_type | text | vegan / vegetarian / eggetarian / non_vegetarian |
| meal_type | text | breakfast / lunch / dinner / snack (most common; used as the ML classification target -- see docs/ml_methodology.md) |
| cuisine | text | indian / continental / other |
| allergens | text | "\|"-separated list from: milk, egg, gluten, peanut, tree_nut, soy, shellfish, fish |
| tags | text | "\|"-separated descriptive tags, deterministically computed |
| source | text | Always "demo_reference" for this file |
